# 模型深度指南模板

每篇模型文档建议按下列一级标题组织（可增小节，勿删主块）：

1. **概览** — 一句话定位、LeRobot 中的角色、何时选用
2. **论文精读** — 问题、方法、实验结论、与前作关系；给出可核对的 arXiv/项目链接
3. **LeRobot 中的实现地图** — 目录、配置类、入口函数、mermaid 数据流
4. **示例：如何跑起来** — `uv`/`lerobot-train`/`from_pretrained`；无硬件降级路径
5. **关键代码详解** — 引用真实路径（相对仓库根）+ 分段解释
6. **社区优秀讨论** — Discord / GitHub / HF Blog / 项目页；只写可核实链接，禁止编造对话
7. **调优与常见坑** — 表格式
8. **延伸阅读** — 官方 mdx、阶段教程交叉链接

真实性原则：不确定的社区「传说」不写；写「公开讨论入口」即可。

快速导览不要求照搬全部章节，但至少应包含：定位、仓库实现路径、注册名、
官方文档、最小运行入口和当前限制。
